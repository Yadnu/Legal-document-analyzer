Upload Pipeline (Phases 3–4)

Browser → FastAPI presigns S3 URL → direct PUT → confirm → SQS → Worker: parse PDF (PyMuPDF / LlamaParse / Textract), clause-aware chunking, Voyage embeddings, pgvector + tsvector storage. Idempotent, DLQ-backed.

Q&A Pipeline (Phase 5)

Browser → FastAPI → LLM Gateway → hybrid retrieval (pgvector HNSW + BM25 tsvector, RRF fusion) → Cohere reranking → Claude 3·5 via Bedrock (strict grounding) → clause-cited answer. Groq Llama 3.3 handles cheap supporting steps. "Not in your documents" when nothing supports the claim.

LLM Gateway + Platform (Phases 7–10)

Gateway enforces per-tenant rate limits, tracks token costs, caches semantically similar queries, and fails over between providers. Audit log on every action. Shared workspaces, obligation tracker, and RAG eval harness measuring faithfulness and retrieval precision in CI.
